# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text, including the enforcement guidelines, is available at that
link; the summary below is not a replacement for it.

## Our pledge

We as members, contributors and maintainers pledge to make participation in this project a
harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience, education, socio-economic
status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Scope

This applies in all project spaces (issues, pull requests, discussions, commit messages) and when an
individual is officially representing the project in public spaces.

## Reporting

Report abusive, harassing or otherwise unacceptable behaviour privately to the maintainer through
GitHub (profile → Report abuse) or by email. Reports are reviewed promptly and handled
confidentially; the maintainer will respect the privacy and safety of the reporter.

## Enforcement

Maintainers may take any action they consider appropriate, from a private warning to a permanent ban
from project spaces, following the Contributor Covenant enforcement guidelines. Maintainers who do
not follow or enforce this code in good faith may face consequences determined by other project
leaders.
